Description

The banner reports an OpenSSH release older than 7.4 (December 2016), the release that removed server support for the obsolete SSH-1 protocol. Such old releases lack years of upstream security fixes. OpenSSH does not publish an end-of-life schedule, so only clearly outdated releases are flagged. Linux distributions often backport security fixes without changing the upstream version number, so the banner version may not reflect the actual patch status. Verify against the vendor's package version before acting.

Recommendation

Upgrade OpenSSH through a supported operating system release or to a current upstream version, and disable legacy key exchange algorithms and ciphers.
